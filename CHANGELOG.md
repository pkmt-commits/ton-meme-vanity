# Изменения

## 1.1.0 — ядро v13: оценка на видеокарте, в 2 раза быстрее, до 4 адресов с одного ключа

- **Сито v5-lite** (`cuda/v5lite.inc`): видеокарта сама считает оценку v5 — та же разметка на слова, тот же словарь
  (~47 тыс. слов, `cuda/v5dict.h` из `src/gpu_dict_v5.mjs`) и веса. Старые «правила слов» пропускали ~25% адресов
  с оценкой 150+ (замер на 200 млн случайных адресов), v5-lite — 99% при той же скорости: хороших находок ~в 4 раза
  больше, а Node получает в 20 раз меньше кандидатов. Флаг `--v5t` (по умолчанию `--save-min − 10`), сверка
  `ref/check_v5lite.mjs` в setup, инструменты замера `src/recall_sample.mjs` / `src/recall_eval.mjs`, режим ядра `flags`.

- **Окно 16 бит** для умножения на кривой: таблица 60 МБ (`cuda/tbl16.bin`, генерирует `npm run setup`) — 16 сложений
  точек на ключ вместо 64. Ключи и адреса прежние (импорт по сиду не меняется). Нет таблицы — ядро работает старым путём.
- **Индекс словаря по трём «пробежкам»**: детектор слов перебирает только подходящие слова (+20–40%), результат
  тот же, что у эталона (`validate`).
- **`--versions 1..4`**: от одного ключа проверяются адреса W5, V4R2, V3R2, V3R1 — почти даром (2 SHA-256 вместо
  умножения на кривой). MyTonWallet показывает все четыре версии (Настройки → Wallet Versions). Адресов в секунду
  в ~2.2 раза больше, чем с одной W5. По умолчанию — только W5.
- Самопроверка: 100 сверок с `@ton/ton` (4 версии, с таблицей и без).
- **«Красота TON-адреса»** (`docs/index.html`, `npm run build:checker`): проверка любого адреса оценкой v5 прямо в браузере —
  спрятанные слова и узоры, очки, редкость («1 из N»), поиск-демонстрация на 10 секунд. Для GitHub Pages.
- **«Свой красивый TON-адрес»** (`docs/generate.html`, `npm run build:generator`): поиск прямо в браузере, без видеокарты
  и установки. Ключи — `crypto.getRandomValues`, не покидают устройство. Быстрая генерация ключей на tweetnacl
  (`web/keygen.js`: таблица 8 бит + пакетное обращение, ~28 тыс. ключей/с на ядро — в 6 раз быстрее noble), адреса
  4 версий (`web/address.js`), предфильтр v5-lite на JS (`web/lite.js`), самопроверка по векторам `@ton/ton` при запуске.
  На 15 потоках Ryzen 7 — ~580 тыс. адресов/с.
- Проверено вживую: генератор на телефоне, импорт ключей всех 4 версий в MyTonWallet (Wallet Versions).
- README на английском: `README.en.md`.
- Безопасность: случайность прямо у ОС (`BCryptGenRandom` / `getrandom`) с проверками; сиды находок стираются из
  видеопамяти сразу после передачи, база — при выходе (CUDA не очищает память между процессами);
  `.claude/settings.json` запрещает ИИ-агентам Claude Code читать файлы с ключами; предупреждение про журнал буфера.
- Ядро завершается само, если обёртка умерла (раньше могло остаться работать «сиротой»).
- Обёртка: `gems.jsonl` читается потоком (раньше файл больше ~512 МБ ронял старт), ядро перезапускается после
  сбоя (до 5 раз в час) с сообщением в Telegram.

## 1.0.0 — первая публичная версия

- GPU-ядро (CUDA): ed25519 + адрес W5 (v5r1), сито по словам/узорам, термо-регулятор (NVML).
- Сид = `SHA-256(база ‖ номер)` — ключи независимы друг от друга.
- Оценка «смешности» v5 (частотная сегментация + бонусы за темы, обособленность, фразы, растяжки, смайлы, мем-числа).
- Обёртка: проверка каждого ключа `@ton/ton`, `gems.jsonl`, Telegram-бот с 👍/😐/👎/⭐, дашборд.
- `npm run setup` — установка одной командой; `npm run top` — находки без ключей; `AGENTS.md` для ИИ-агентов.
